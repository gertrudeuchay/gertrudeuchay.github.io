AWS Cost Optimization

Multi-Account Cost Optimization Across NNPC's AWS Organization

Cost optimization across compute, storage and database workloads, combining rightsizing, resource modernization and commitment planning to improve AWS cost efficiency.

Project Overview

Led an AWS cost optimization initiative across NNPC's multi-account AWS Organization and Descasio-managed client accounts, analyzing approximately 250 optimization recommendations across compute, storage and database resources.

$12K+ Monthly AWS cost savings
$144K+ Annualized AWS savings

The initiative delivered over $12,000 in monthly AWS cost savings, equivalent to more than $144,000 in annualized savings, through a combination of workload rightsizing, infrastructure modernization and commitment planning.

The optimization approach was designed to ensure that long-term Reserved Instance and Savings Plan commitments were based on an accurate post-optimization usage baseline rather than inflated historical consumption.

Business Challenge

The AWS environment had accumulated cost inefficiencies across several resource types, including oversized EC2 and RDS instances, legacy EBS volume configurations and unoptimized ECS Fargate workloads.

With approximately 250 recommendations to evaluate, the challenge was not simply identifying potential savings. Recommendations needed to be prioritized, validated against workload requirements and implemented in a controlled sequence without compromising performance or reliability.

A further challenge was ensuring that long-term commitments were based on an accurate usage baseline. Purchasing Reserved Instances or Savings Plans before rightsizing could result in committing to capacity that was no longer required.

Optimization Strategy

The optimization process followed a rightsize-first, commit-second strategy. This ensured that long-term AWS commitments were based on actual post-optimization usage rather than legacy consumption patterns.

1. Discovery

Collected cost and utilization recommendations from AWS Cost Optimization Hub, AWS Compute Optimizer and AWS Cost Anomaly Detection across the AWS environment.

2. Analysis & Prioritization

Consolidated approximately 250 recommendations into a structured tracker and categorized them according to implementation effort and projected savings.

This created a practical way to prioritize high-impact, lower-effort opportunities while also tracking larger infrastructure changes.

3. Implementation

Implemented optimization actions across EC2, ECS Fargate, EBS and RDS workloads, including rightsizing, storage modernization and migration to Graviton-based RDS instance classes.

4. Baseline Validation

After rightsizing, a 14-day lookback period was used to observe the resulting usage pattern before making long-term commitment decisions.

5. Commitment Planning

The corrected post-rightsizing baseline was then used to inform Compute Savings Plan and RDS Reserved Instance decisions.

Key Technical Changes

EC2 Rightsizing

Reviewed EC2 utilization and sizing recommendations and adjusted instances where workload behavior supported a smaller or more appropriate configuration.

EBS gp2 to gp3 Migration

Upgraded applicable EBS volumes from gp2 to gp3 and reduced IOPS where workload requirements allowed it, modernizing the storage configuration while improving cost efficiency.

RDS Graviton Migration

Migrated all 13 RDS instances in the eu-west-1 environment from previous-generation instance classes to Graviton-based db.r6g classes.

The migration required coordination across the affected database workloads while maintaining availability and compatibility.

ECS Fargate Rightsizing

Reviewed ECS Fargate task sizing and adjusted compute allocations where utilization patterns indicated that workloads could operate efficiently with lower resource allocations.

Technical Challenges & Solutions

Rightsizing Without Impacting Workloads

Cost recommendations could not be treated as automatic changes. Compute Optimizer recommendations were reviewed against actual workload behavior and requirements before implementation.

This helped balance cost reduction with the need to maintain workload performance and reliability.

Commitment Sequencing

Purchasing commitments against the original usage baseline could have resulted in over-commitment because some workloads were oversized.

The solution was to complete rightsizing first, observe the new usage pattern for 14 days and then use the resulting baseline to inform commitment decisions.

Optimization at Scale

Managing approximately 250 recommendations required more than reviewing AWS console recommendations individually.

A structured Excel tracker with effort classification, savings calculations and a live dashboard was created to provide a consistent way to prioritize, monitor and report optimization activities.

Cost Optimization Strategy

The optimization work delivered over $12,000 in monthly AWS cost savings by combining multiple optimization levers rather than relying on a single cost reduction measure.

Savings opportunities were evaluated based on both financial impact and implementation effort. Quick, lower-risk opportunities such as EBS gp2-to-gp3 upgrades were addressed alongside larger structural changes such as RDS Graviton migration and compute rightsizing.

The rightsize-first, commit-second sequencing was itself an important cost control measure. By correcting resource sizing before purchasing long-term commitments, the resulting Savings Plan and Reserved Instance decisions were based on a more accurate consumption baseline.

This approach helped turn cost optimization from a one-time exercise into a structured process for continuous cloud cost governance.
