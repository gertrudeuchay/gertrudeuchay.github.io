Enterprise AWS Migration

Migration of 23 Enterprise Workloads to AWS

Overview

Supported the migration of 23 enterprise workloads from an on-premises environment to AWS, with focus on migration planning, infrastructure, networking, replication, connectivity and post-migration optimization.

Business Challenge

The organization needed to move its existing workloads to AWS while maintaining reliable connectivity, appropriate security controls and operational continuity throughout the migration.

My Role

  • Supported workload assessment and migration planning.
  • Contributed to AWS infrastructure and network design.
  • Supported workload replication and migration activities.
  • Configured and troubleshot AWS connectivity.
  • Investigated migration and infrastructure issues.
  • Supported post-migration stabilization and optimization.

Architecture

The migration architecture connected the existing on-premises environment to AWS and used AWS migration, networking and infrastructure services to support workload replication and migration.

The target AWS environment was designed with appropriate network segmentation, private connectivity and security controls to support the migrated workloads.

Key AWS Services

  • AWS Application Migration Service (MGN)
  • Amazon EC2
  • Amazon VPC
  • Amazon S3
  • VPC Endpoints
  • AWS Systems Manager
  • Security Groups
  • AWS IAM
  • Amazon CloudWatch

Key Technical Challenges

Private Network Connectivity

The migration environment required reliable connectivity between the replication infrastructure and AWS services without relying on unnecessary public exposure.

Migration Connectivity

Investigated connectivity and configuration issues affecting migration components and AWS service communication.

Infrastructure Troubleshooting

Diagnosed infrastructure, networking and security configuration issues during the migration process and supported resolution through testing and configuration changes.

Security Considerations

  • Network segmentation using VPC subnets.
  • Controlled traffic using security groups.
  • Private connectivity to required AWS services.
  • IAM-based access control.
  • Minimized unnecessary public exposure.

Cost Considerations

Infrastructure sizing and AWS resource selection were considered as part of the migration and post-migration optimization process, with the goal of maintaining the required workload performance while avoiding unnecessary cloud expenditure.

Outcome

Supported the successful migration of 23 enterprise workloads to AWS and contributed to the stabilization, troubleshooting and optimization of the resulting cloud environment.
